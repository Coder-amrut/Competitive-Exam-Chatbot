# 🎯 AI स्पर्धा परीक्षा स्टुडिओ (AI Marathi Competitive Exam Studio)

अत्याधुनिक, वेगवान आणि मराठी भाषेतील स्पर्धा परीक्षा (MPSC, तलाठी, पोलीस भरती, ZP, संयुक्त गट ब व क) साठी तयार केलेले **AI MCQ Exam Studio**.

---

## ✨ प्रमुख वैशिष्ट्ये (Key Features)

1. **अस्सल मराठी भाषेतील प्रश्न (Pure Marathi MCQs)**:
   - मराठी व्याकरण व शब्दसंग्रह (संधी, समास, प्रयोग, विभक्ती, अलंकार)
   - महाराष्ट्र व भारताचा इतिहास (छत्रपती शिवाजी महाराज, समाजसुधारक, १८५७ चा उठाव)
   - भूगोल व पर्यावरण (सह्याद्री, नद्या, धरणे, काळी कापसाची मृदा, कास पठार)
   - भारतीय राज्यघटना व पंचायत राज (कलम, ७३ वी व ७४ वी घटनादुरुस्ती, ग्रामपंचायत)
   - अंकगणित व बुद्धिमत्ता (नफा-तोटा, संख्या मालिका, काळ-काम-वेग, सरासरी)
   - सामान्य विज्ञान (भौतिक, रसायन, जीवशास्त्र, जीवनसत्त्वे)
   - चालू घडामोडी (ISRO मोहीमा, भारतरत्न, जागतिक पर्यावरण दिन)

2. **अभ्यासक्रम व सानुकूल विषय इनपुट (Custom Syllabus & Topic Input)**:
   - युझर स्वतःचा कोणताही विषय, चाप्टर किंवा नोट्स टेक्स्टबॉक्समध्ये पेस्ट करू शकतो.
   - सिस्टीम त्या दिलेल्या अभ्यासावर आपोआप मराठी वस्तुनिष्ठ प्रश्न तयार करते.

3. **रिअल-टाईम टायमर व चेतावणी (Real-Time Exam Countdown Timer)**:
   - ५, १०, १५, २०, ३० मिनिटे किंवा सानुकूल मिनिटे निवडा.
   - वेळेची बचत न झाल्यास स्वयंचलित सबमिट.
   - शेवटच्या ५ मिनिटांत पिवळा आणि शेवटच्या २ मिनिटांत लाल दिवा व चेतावणी बीप.

4. **TCS iON / MPSC राष्ट्रीय परीक्षा दर्जाचा इंटरफेस (Exam Room)**:
   - **प्रश्न तक्ता (Question Palette)**: हिरवा (सोडवलेले), जांभळा (पुनरावलोकन खूण केलेले), लाल (न सोडवलेले).
   - **उत्तर पुसणे (Clear Response)** व **खूण करा (Flag for Review)** पर्याय.
   - **कीबोर्ड शॉर्टकट्स**: पर्यायांसाठी `1, 2, 3, 4`, पुढील प्रश्नासाठी `Right Arrow` किंवा `N`, मागीलसाठी `Left Arrow` किंवा `P`, आणि खूण करण्यासाठी `F`.

5. **निकालाचे सखोल विश्लेषण (Scorecard & Solutions with Explanations)**:
   - एकूण गुण, टक्केवारी, सरासरी वेळ आणि ०.२५ ऋण गुण (Negative Marking).
   - प्रत्येक प्रश्नाचे योग्य उत्तर आणि त्यामागील **सविस्तर मराठी स्पष्टीकरण व नियम**.
   - **प्रिंट / PDF सेव्ह**: एका क्लिकवर गुणपत्रक आणि उत्तरपत्रिका सेव्ह करता येते.

6. **📱 संपूर्ण डिव्हाईस-फ्री आणि PWA (Device-Free & Universal App)**:
   - **कोणतेही डिव्हाईस बंधन नाही**: अँड्रॉइड फोन, आयफोन (iOS), आयपॅड, टॅबलेट, लॅपटॉप किंवा डेस्कटॉप संगणकावर एकाच सहजतेने चालते.
   - **मोबाईल-फ्रेंडली स्लाइड-अप पॅलेट**: मोबाईलवर एक-टॅप प्रश्न तक्ता (Drawer), अंगठ्याखालील स्टिकी ॲक्शन बटणे, आणि हेप्टिक व्हायब्रेशन.
   - **थेट इन्स्टॉल (PWA)**: कोणत्याही ॲप स्टोअरशिवाय थेट मोबाईलच्या होमस्क्रीनवर 'ॲप' म्हणून इन्स्टॉल करा.
   - **100% ऑफलाइन कार्यक्षम (Service Worker)**: इंटरनेट किंवा सर्व्हर नसतानाही सर्व प्रश्न, टायमर आणि निकाल अखंड सुरू राहतात.

7. **ऑटोमॅटिक ऑडिओ व Google AI API इंटिग्रेशन**:
   - कोणत्याही बाह्य ऑडिओ फाईल्सची गरज नाही (Web Audio API द्वारे ध्वनी).
   - Google AI Studio API की सक्रियपणे जोडलेली आहे.

## 🚀 परीक्षा सुरू कशी करावी? (How to Run)

### पर्याय १: थेट ब्राउझरमध्ये उघडा
- `index.html` फाईलवर डबल-क्लिक करा किंवा Chrome / Edge ब्राउझरमध्ये ड्रॅग करा.

### पर्याय २: लोकल सर्व्हर (Local Server)
स्थानिक सर्व्हर चालू असल्यास थेट या लिंकवर जा:
```
http://localhost:8080
```
किंवा टर्मिनलमध्ये:
```powershell
python -m http.server 8080
```
